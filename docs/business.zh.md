# 业务说明

[English](business.md) | 中文

## 产品概述

NPC GUI 是 NPS 的桌面客户端，用于管理 [djylb/nps](https://github.com/djylb/nps) 的 npc 内网穿透进程。应用把 npc 原先依赖命令行的配置、启动、日志查看和版本维护整合到同一个桌面界面中。

产品面向需要长期运行内网穿透连接的个人开发者和运维人员。一个应用可以管理多个 NPS 服务端连接，每个连接拥有独立的配置、进程、状态和日志。

## 目标用户

- 需要在多个 NPS 服务端之间切换的个人开发者。
- 需要同时维护多个内网穿透连接的运维人员。
- 需要在不打开终端的情况下查看连接状态和日志的用户。
- 需要统一管理 npc 版本和客户端版本的用户。

## 核心业务场景

### 多服务端连接管理

用户可以为每个 NPS 服务端创建独立档案，并分别配置地址、vkey、连接方式、代理、认证和断线参数。应用为每个档案启动一个独立 npc 进程，多个连接可以并行运行。

### 启动命令导入

NPS 管理台会生成 npc 启动命令。用户可以把命令粘贴到导入入口，应用会解析服务端地址、vkey 和连接方式，并填充到连接档案中。解析过程不会执行命令本身。

### 连接运行与故障排查

应用展示连接状态、PID、运行时长、重连次数和最后错误。日志控制台支持按档案、等级和关键词查看日志，并支持导出，便于定位连接失败、认证错误或网络异常。

### 版本维护

应用可以检测本机 npc，也可以从上游 GitHub Releases 下载 npc，并完成 SHA-256 校验和版本复核。客户端自身通过本项目 GitHub Releases 更新，npc 更新与客户端更新相互独立。

### 长期驻留

应用提供系统托盘、开机自启和系统通知。启用托盘后，关闭窗口会收起到托盘，连接可以继续运行；用户可以从托盘恢复窗口、启动或停止全部连接。

## 核心业务能力

- **连接档案**支持服务端地址、vkey、TCP/TLS/KCP/QUIC/WS/WSS、代理、DNS/NTP、断线参数、认证和限速等配置。
- **命令填充**会在用户粘贴 npc 启动命令后自动填写基础字段，并且不会执行该命令。
- **多实例运行**使一个档案对应一个 npc 进程，多个档案之间互不影响。
- **受管配置**由应用为每个档案生成独立的 npc.conf，vkey 不进入进程启动参数。
- **实时状态**包括在线、重连中、异常和停止，并展示运行数据和最后错误。
- **日志控制台**支持过滤、搜索、跟随滚动、自动换行、清空和导出，日志以 0600 权限落盘。
- **NPC 核心管理**支持自动检测、本地选择、上游下载、SHA-256 校验和版本复核。
- **客户端更新**通过 GitHub Releases 完成检查、下载、校验、helper 替换和失败回滚。
- **系统集成**提供托盘菜单、开机自启和连接异常、恢复、版本更新通知。

## 业务流程

### 首次使用

1. 应用进入引导页，并提供自动下载 npc、选择本地文件或检测 PATH 三种方式。
2. 用户准备 npc 后，可以创建第一个连接档案。
3. 用户填写服务端地址、vkey 和连接方式，或者粘贴 NPS 启动命令自动填充。
4. 应用保存档案并生成配置文件，用户可以启动连接。
5. 总览页展示运行状态，日志页展示 npc 输出。

### 日常运行

1. 用户从总览页或连接页启动、停止或重启连接。
2. 应用更新连接状态，并把状态和日志推送到界面。
3. 用户可以按档案查看日志、筛选错误或导出日志文件。
4. 用户可以把窗口收起到托盘，连接在后台继续运行。
5. 用户可以从托盘恢复窗口，或启动、停止全部连接。

### 版本维护

1. 应用检查 npc 核心和客户端的新版本。
2. 用户确认更新后，应用下载并校验更新资产。
3. npc 更新在后续启动时生效，客户端更新由 helper 完成替换和重启。
4. 更新失败时，应用保留旧版本或恢复备份。

## 业务边界

- 一个档案对应一个服务端，多服务端场景需要创建多个档案。
- 当前范围不包含 NPS 服务端 Web API、隧道 CRUD 和流量统计。
- 当前范围不包含 npc 系统服务安装。
- 当前范围不包含代码签名、Apple 公证、DMG 和 NSIS 安装包。
- npc 二进制不随客户端分发，应用从上游下载或使用用户提供的本地文件。
- 客户端更新和 npc 更新使用不同的发布源，二者互不影响。

## 业务价值

- 应用把命令行操作整理为可视化工作流，降低 npc 的日常使用门槛。
- 应用通过独立配置文件和进程隔离，支持多个服务端并行运行。
- 应用统一管理 vkey、配置、日志和版本，减少重复操作。
- 应用提供状态、日志和通知，缩短连接异常的定位时间。
- 应用提供 GitHub Releases 更新链路，降低客户端和 npc 的维护成本。
