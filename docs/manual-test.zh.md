# 手工验收清单

[English](manual-test.md) | 中文

手工验收清单用于发布前的本机检查。每个条目都描述一个可观察的预期结果。

## 环境

隔离测试使用工作区数据目录，命令示例如下：

~~~bash
export NPC_GUI_DATA_DIR="$PWD/.cache/appdata"
wails dev
~~~

浏览器可以通过 http://localhost:34115 调用真实 Go 后端。前端 mock 模式由 pnpm dev 启动。

## 首次引导

- [ ] 没有 npc 时，应用进入引导页；下载按钮显示进度并支持取消。
- [ ] 下载完成后，引导页展示版本和路径，并允许进入下一步。
- [ ] 选择本地 npc 后，应用执行 -version 并校验版本。
- [ ] 非法文件会被拒绝，并显示可读错误。
- [ ] 自动检测可以发现 PATH 或 GUI 管理的 npc。

## 连接档案

- [ ] 新建档案时，必填项校验正常生效。
- [ ] 在新建连接页粘贴 ./npc -server="..." -vkey="..." -type="tcp" 后，名称、服务端、vkey 和连接方式会自动填充。
- [ ] 多服务端命令只填充第一个服务端，并提示使用「导入命令」批量创建。
- [ ] 服务端地址包含多个逗号值时，应用拒绝保存。
- [ ] vkey 默认以掩码显示，显示和隐藏操作正常。
- [ ] 保存档案后，应用生成 profiles/<id>/npc.conf，权限为 0600。
- [ ] 预览内容中的 vkey 默认打码，显示密钥后可以查看明文。
- [ ] 导出配置时，应用打开系统保存对话框。
- [ ] 运行中的档案被修改后，界面显示“待重启”。
- [ ] 粘贴 NPS 命令后，应用可以拆分为多个档案，且不会执行命令本身。
- [ ] 重复段落和 [common] 覆盖等扩展错误会被拒绝。

## 进程与状态

- [ ] 启动不可达服务端时，状态从 starting 进入 reconnecting，日志实时滚动。
- [ ] 停止连接后，进程在 5 秒内消失，runtime PID 文件被删除。
- [ ] 两个档案并行运行时，状态、日志和 PID 相互独立。
- [ ] 停止连接后，卡片 PID 显示 --，不保留旧 PID。
- [ ] 未启用托盘且存在运行中的连接时，关闭窗口会弹出确认；确认后全部连接停止并退出，取消后应用保持运行。
- [ ] 正常退出后没有残留 npc 进程。
- [ ] 启用“开机自启”后，macOS 生成 ~/Library/LaunchAgents/com.npcgui.desktop.plist，Windows 生成 HKCU Run 项，Linux 生成 ~/.config/autostart/npc-gui.desktop。
- [ ] 以 --hidden 启动时，窗口不显示，托盘图标可用，托盘可以显示主窗口。
- [ ] 托盘菜单提供全部启动、全部停止、开机自启切换和退出。
- [ ] 启用“关闭时收起到托盘”后，关闭窗口只隐藏窗口，npc 进程继续运行；托盘退出会停止全部进程。
- [ ] 连接异常、恢复或发现客户端新版本时，应用发送系统通知；关闭通知开关后不再发送。
- [ ] 应用被强制关闭后重新启动时，启动阶段会结束上次留下的 npc 进程，不再显示残留告警。
- [ ] 当残留进程的命令行无法确认时，应用不会误杀，只显示提示。

## 日志

- [ ] 全部日志和单档案日志的切换结果正确。
- [ ] 等级和关键词过滤结果正确。
- [ ] 跟随按钮和滚动行为正确。
- [ ] 清空操作只影响当前档案。
- [ ] 导出文件的内容与界面显示一致。
- [ ] 日志文件存在且权限为 0600。

## npc 版本

- [ ] 自动下载最新 npc 后，SHA-256 与 GitHub asset digest 匹配。
- [ ] 下载完成后，npc -version 的输出正确。
- [ ] 选择候选版本后，当前 npc 可以正常切换。
- [ ] 上游下载失败时，界面显示可读错误和重试路径。

## 客户端更新

- [ ] 开发构建显示 disabled，并且不访问 GitHub。
- [ ] 发布构建或使用 NPC_GUI_UPDATE_REPO/NPC_GUI_UPDATE_API 测试源时，客户端可以检查到新版本。
- [ ] 下载进度、取消操作和 checksum 错误提示正常。
- [ ] “重启并更新”会先停止连接；应用退出后，helper 完成替换并重启。
- [ ] 旧版本 .old 备份存在，替换失败时可以恢复。
- [ ] macOS AppTranslocation 或只读目录会给出明确提示。
- [ ] 更新日志可以从设置页打开。

## 构建

后端测试：

~~~bash
go test ./...
go vet ./...
~~~

前端检查与构建：

~~~bash
cd frontend
pnpm typecheck
pnpm test
pnpm build
cd ..
~~~

生产打包：

~~~bash
wails build -clean
~~~

启动应用：

~~~bash
open build/bin/npc-gui.app
~~~
